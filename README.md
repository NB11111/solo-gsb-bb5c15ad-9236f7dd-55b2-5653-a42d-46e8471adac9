# 合唱视线遮挡检查台（Choir Sightline Checker）

在平面舞台上拖放**指挥**与**圆形站位**、调整人体半径，系统实时判断每位演唱者到指挥的视线线段是否被其他站位圆遮挡，按**沿视线最近的遮挡者**着色，并列出全部受阻关系。前后端共用同一套几何判定核心，支持场景 JSON 导入/导出与服务端校验。

## 快速开始（单条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**（服务端口 `8080`，可用 `PORT` 环境变量覆盖；Compose 已将宿主 8080 映射到容器 8080）。

> 若使用旧版 Docker Compose：`docker-compose up --build`。

镜像构建过程会自动完成依赖安装（`npm ci`）、几何核心单元测试与前后端构建；运行阶段为仅含构建产物的精简镜像，无需 node_modules。

## 功能

- **拖放编辑**：拖动指挥（▲）与站位圆调整位置；双击舞台空白处添加演唱者；点击选中后用滑杆或**滚轮**调整人体半径（0.10–1.00 m）。
- **实时判定**：每次修改即时重算全部视线，绿色=通畅、琥珀色虚线=相切擦边、彩色=被遮挡。
- **最近遮挡者着色**：被遮挡者的填充色与其**沿视线最近遮挡者**的身份色一致（侧栏列表与站位圆描边的彩色圆点一一对应），并在线段上标出进入点。
- **受阻关系列表**：逐条列出「谁 → 指挥 被谁遮挡（进入距离、侵入深度）」，共线时的其余遮挡者、相切与退化情况单独分组。
- **遮挡关系图谱**：舞台下方实时显示「演唱者 → 沿视线最近遮挡者」有向图；节点按舞台站位布局（重合站位自动展开），填充色区分通畅/相切/被遮挡/退化。点击图节点与舞台站位、侧栏详情联动选中；选中后高亮其可达遮挡链路，互相遮挡形成的循环以品红色标出并在标题栏列出。场景拖动、导入或载入预设后图谱立即重算。
- **JSON 导入/导出**：导出当前场景为 JSON 文件；导入时完整校验并给出全部错误。
- **服务器校验**：一键将场景 POST 到后端 `/api/analyze`，与前端结果比对（两端共用 `shared/geometry.ts`，结果必然一致）。
- **自动解遮挡**：选中被遮挡的演唱者后，侧栏面板按 0.5 m 网格采样舞台并多轮细化搜索其**最小位移**候选；点击候选（或舞台上的编号圆点）可预览，确认后只移动该演唱者并实时刷新遮挡统计。
- **指挥站位热区**：工具栏开启「🛰 指挥站位热区」后，在舞台前方 x∈[-1, W+1]、y∈[-2.8, 0] 区域按 0.25 m 网格逐点模拟指挥位置（复用同一套几何判定核心）；每点按**通畅人数为主、相切人数为次**计算分数（退化视线计为不可用），舞台上叠加可缩放（滚轮/滑杆，可拖动平移）的五档红→绿热区。侧栏列出分数最高且彼此至少相距 1 m 的 3 个候选并展示通畅/相切/遮挡/退化明细；**点击候选只在舞台上预览该位置的全部视线（真实指挥不移动），确认「应用指挥位置」后才生效**。任何场景编辑（拖动、半径、增删人员、导入、预设）后热区与候选立即重算；空场景时舞台与侧栏给出明确提示。
- **测试预设**：工具栏可载入「共线测试」「相切测试」「重合测试」等边界场景。

## 判定规则（精确语义）

视线定义为**演唱者眼睛（站位圆圆心）到指挥点的线段**，其他站位圆按线段-圆相交判定：

| 情形 | 条件（d = 圆心到线段距离，r = 半径） | 结果 |
| --- | --- | --- |
| 遮挡 | d < r − ε | `blocked`，按进入参数 t 最小者为最近遮挡者 |
| 相切 | \|d − r\| ≤ ε | `tangent`（擦边，**不**判为遮挡，单独标注） |
| 通畅 | d > r + ε | `clear` |
| 退化 | 演唱者与指挥距离 < 1e-9 m | `degenerate` |

- 容差 ε = `TANGENT_EPS = 1e-6` m（见 `shared/geometry.ts`），保证相切边界判定确定、不抖动。
- **重合**：站位圆包含眼睛或指挥时按相交处理（进入参数钳制到 0/1）；圆心重合的站位、与指挥重合的站位会在警告区单独列出。
- **多人共线**：全部遮挡事件按沿视线进入参数 `tEnter` 升序排列，最近的非相切遮挡者决定着色，其余遮挡者在受阻关系中列出。

## 遮挡关系图谱（图语义）

`buildOcclusionGraph`（共享核心）把当前分析转成有向图：**每个被遮挡的演唱者向自己沿视线最近的遮挡者连一条边**，因此每个节点出度 ≤ 1，从任意节点出发的可达链路唯一——要么终止于通畅/相切/退化节点（无出边），要么进入一个有向**循环**（如两圆互相包含对方眼睛时形成 A↔B 互挡）。`occlusionChainFrom` 返回选中者的可达节点、可达边（含回到循环起点的闭合边）与循环部分；图谱视图据此高亮链路并以品红色标出循环节点与边。图谱由分析结果派生，任何场景编辑（拖动、滚轮调半径、导入、载入预设）都会立即重算。

## 自动解遮挡（搜索语义）

选中演唱者后可在侧栏「🎯 自动解遮挡」面板执行搜索（`findUnblockCandidates`，位于共享核心）。搜索**只评估候选位置、不修改任何人**，只有点击「应用」才移动被选中者；任何编辑都会使旧结果标记为过期。

候选位置必须**同时**满足：

1. **留在舞台内**：整个站位圆（含半径）位于舞台矩形内，即圆心 ∈ [r, W−r] × [r, D−r]；
2. **间距**：与其余每个站位圆的圆心距 ≥ 自身半径 + 对方半径（相切允许，侵入 `< r₁+r₂−ε` 不行）；
3. **视线**：新位置到指挥的线段不被任何其他站位圆侵入（相切擦边允许，判为 `blocked` 或与指挥重合的退化才算违规）。

搜索过程：在合法圆心矩形内按 0.5 m 网格粗采样（边界与当前坐标均取到），评估全部点后取位移最小的 5 个可行种子做 5 轮贪心细化（8 邻域下降，步长 0.25 m 逐轮减半至 ≈0.016 m），候选去重后**按位移距离升序**返回前 3 个，并附距当前位置最近的 3 个不可行采样点及其全部违规原因（出界 / 间距不足（含对方姓名与侵入量）/ 视线仍被挡（含遮挡者）/ 退化）。当前位置已通畅时直接提示无需移动；舞台小到放不下站位圆或采样后无可行点时，明确提示无法解遮挡。

## 指挥站位热区（评分语义）

开启热区模式后调用共享核心的 `buildConductorHeatZone(scene)`：在舞台前方矩形 **x∈[-1, W+1]、y∈[-2.8, 0]**（W 为舞台宽）内按 **0.25 m** 等距网格枚举候选指挥位置（x 轴以 -1 起、y 轴以 0 起，保证两端边界均被采样），对每个点评估全部演唱者到该点的视线：

- **评分（字典序）**：`分数 = 通畅人数 × (总人数 + 1) + 相切人数`——先比通畅人数（主），相同再比相切人数（次）；被遮挡与**退化**（演唱者与候选指挥位置距离 < 1e-9 m）均不计分，因此有退化视线的点不会因此受益。
- **分档着色**：按通畅人数占比 `ceil(5 × clear / total)` 归入 1~5 档（红 → 绿），无任何通畅视线为灰色 0 档（不可用）；色块为半透明叠加，不遮挡视线与站位。
- **候选**：全部采样点按分数降序（同分按 x 升序、y 降序，保证确定）贪心挑选**彼此圆心距 ≥ 1 m** 的前 3 个；分数为 0 的点不作为候选（舞台全遮挡时明确提示）。每个候选附带该点的完整 `Analysis`，点击时舞台**只预览全部视线**（空心三角为候选指挥，真实指挥淡化并以虚线相连），确认「应用」后指挥才真正移动。
- 热区只依赖**舞台尺寸与站位**（不依赖当前指挥位置），因此添加/移动/删除站位、改半径、导入或载入预设后立即重算，而拖动真实指挥不会引起热区重算；预览的候选一旦因编辑失效会自动取消预览。人数较多（上限 500）时内部以最大半径为边长的均匀空间网格沿视线扫描，保持交互流畅。

npm run dev        # 并行启动后端(8080)与前端 Vite(5173，代理 /api)

## JSON 场景格式

```json
{
  "version": 1,
  "stage": { "width": 12, "depth": 8 },
  "conductor": { "x": 6, "y": -1.5 },
  "singers": [
    { "id": "s1", "name": "S1", "x": 3, "y": 2, "radius": 0.3 }
  ]
}
```

- 单位为米；舞台左上角为原点，y 向下为舞台纵深，指挥可位于 y < 0 的舞台前方区域。
- 校验规则：半径 0.05–1.5 m，舞台宽 2–40 m、深 2–30 m，演唱者 ≤ 500 人，id 唯一。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| POST | `/api/analyze` | 请求体为场景 JSON，返回 `{ ok, analysis }`（每位演唱者的状态、按距离排序的遮挡事件、警告与统计）；非法场景返回 400 及全部错误 |

```
├── shared/geometry.ts        # 几何判定核心（前后端共用）+ 场景校验 + 自动解遮挡搜索 + 遮挡关系图谱 + 指挥站位热区
├── shared/geometry.test.ts   # 单元测试：相切/重合/共线/退化/解遮挡/图谱/热区评分分档候选与快路径一致性
├── server/src/index.ts       # Express：静态托管 + /api/health + /api/analyze
├── client/src/
│   ├── Stage.tsx             # React + SVG 舞台（拖放/滚轮/候选预览/热区分档渲染与缩放平移）
│   ├── GraphView.tsx         # 遮挡关系图谱（有向图/链路高亮/循环标记/联动选中）
│   ├── HeatmapPanel.tsx      # 指挥站位热区侧栏（分档图例/候选通畅相切遮挡退化明细/预览与应用）
│   ├── heatColors.ts         # 热区五档配色（舞台半透明色块与侧栏图例共用）
│   ├── Sidebar.tsx           # 侧栏：统计、选中编辑、热区面板、自动解遮挡面板、受阻关系
│   └── UnblockPanel.tsx      # 自动解遮挡面板（搜索/候选/不可行原因/预览状态）
├── Dockerfile                # 多阶段：构建(含测试) → 精简运行时
└── docker-compose.yml        # 单服务，端口 8080
```
